OHS Documentation Designs - Offline Package

Quick launch — no setup required
1. Double-click OPEN_DESIGNS.html.
2. Browse and interact with both designs.

Alternative launchers
- macOS: double-click "Launch OHS Designs.command"
- Windows: double-click "start.bat"
- Linux: run ./start.sh

No local server, Node.js, Python, installation, or internet connection is required. Links to GitHub and the OHS Foundation website still require internet access.

Optional local server
If your browser restricts a file-based interaction, run "node serve.mjs" and open http://localhost:8080/compare/.

Pages
- compare/index.html  Side-by-side comparison
- initial/index.html  Technical documentation homepage
- index.html          Instruction-page template

Search, navigation, tabs, drawers, feedback controls, and comparison controls are clickable.
