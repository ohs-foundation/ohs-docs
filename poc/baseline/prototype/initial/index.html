Run the reference client.

The reference client is a sample app built on the OHS Player runtime. Start with desktop, then continue with Android, iOS, or web.

$ git clone https://github.com/ohs-foundation/ohs-player-reference-client-app.git
$ cd ohs-player-reference-client-app
$ ./gradlew :ohs-player-reference-app:run
