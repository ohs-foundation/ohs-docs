## Where to start

Choose a pathway below to begin, or [explore capabilities by topic](#capabilities).

| Developer Goal | First Step | Where to Go |
| --- | --- | --- |
| Build a custom mobile or multiplatform application | Integrate Kotlin FHIR libraries for data models, on-device storage, sync, and form rendering | [Explore FHIR Foundations](/fhir-foundations/) |
| Extend an existing application with backend services | Deploy gateway access rules, custom endpoints, or SQL-on-FHIR analytics pipelines | [Reference Backend](/components/reference-backend/) and [Analytics](/components/reference-analytics/) |
| Evaluate or deploy the complete reference platform | Launch the local reference environment and configure frontline screens from FHIR | [Get started with Player](/get-started/) |
| Find source repositories or contribute | Access community discussions, repository issue trackers, and submission templates | [Resources and contributing](/resources/) |
