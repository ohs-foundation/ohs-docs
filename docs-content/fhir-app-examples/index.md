## What it provides

FHIR App Examples contains examples of how Open Health Stack components can be used
together as the foundation for FHIR-based digital health solutions.

## How it differs from OHS Player

The examples are self-contained and scoped to individual components or narrow use cases.
[OHS Player](/ohs-player/) is the full reference composition, with a shared environment,
an administration portal, and a client application intended to be adapted.

## Reference material

Each example carries its own build and run instructions in the component repository.
